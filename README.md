# 声音练习室

录音或导入音频，查看音高与共振峰，辅助声音训练。

[开始练习](https://emmm1e3m.github.io/voice_tuning/)

## 可以做什么

- 实时查看音高（F0）、共振峰（F1、F2）与声区，对照目标范围练习。
- 用钢琴听参考音，回放录音，并将保留的音频下载为 WAV。
- 阅读发声原理、训练方法和读图教程。

音频在浏览器中处理，默认保留最近 20 秒，可调整为 5–120 秒。

## 本地运行

安装 Node.js 后，双击「启动练习器.cmd」；首次启动会自动安装依赖并打开浏览器。

源码位于 `downloads/voice.starbow.top/source/`。
