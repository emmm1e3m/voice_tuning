# Windows 一键启动

双击工作区根目录的 `启动练习器.cmd`。系统需要已经安装 Node.js，建议使用 22.12 或更新的 LTS 版本；脚本不会安装系统软件或请求管理员权限。

- 首次启动自动执行项目内 `npm ci`；以后比对完整的依赖锁文件内容，未变化时直接启动。若 `node_modules` 已被清理，会重新安装。
- 只有本地 `127.0.0.1:7890` 可连接时，本次 npm 安装才添加代理参数，不修改全局 npm 配置。
- 默认使用 `http://127.0.0.1:5173/`，端口被其它程序占用时寻找 5192 以内的空闲端口。发现已运行的本项目页面时直接打开。
- 浏览器在页面就绪后自动打开。保留启动窗口，按 `Ctrl+C` 停止。安装或启动失败时窗口保留中文错误信息。
- 仅在本机监听，不修改防火墙。

排查环境时，可在根目录运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -CheckOnly`；此模式不安装依赖、不启动服务，也不打开浏览器。

开发集成约定：源码 `index.html` 需包含 `<meta name="voice-tuning-app" content="local-integrated">`，用于识别本项目，防止误打开其它服务。
