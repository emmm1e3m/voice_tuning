# 声音练习室使用说明

## 开始练习

1. 顶部依次提供「声音分析」「音高参考」「统计分析」「交互演示」「教学文档」五个页面标签。声音分析页上方的 F0、F1、F2 三卡显示保留窗口的频率中位数与目标中心；点击卡片可阅读对应使用说明。
2. 桌面使用默认展开的「目标频率设置」，手机打开底部目标按钮。选择 a、o、e、i、u、ü 后设置 F0；「随F0推荐」在手册两档元音参考值间插值，切换元音保留 F0。手动修改共振峰后进入手动模式，此时调整 F0 保留 F1/F2。每项只需调整一个中心，参考窗口固定为 F0 ±40 Hz、F1 ±100 Hz、F2 ±150 Hz。
3. 开始录音或导入音频。在同一张图里观察 F0、F1、F2：紫、粉、蓝分别对应三项频率。默认使用对数坐标，可切换线性；图例只控制曲线显示。
4. 上方三卡查看整个保留窗口的概况，回放用于核对听感。图中一层竖直背景表示随时间变化的声区估计，静音与缺口留白；声区开关独立于频率曲线。
5. 用「下载 WAV」保存保留窗口内的音频。默认保留 10 秒；在「配置」中可设为 5–120 秒，导入时长上限同步变化。平滑窗口默认 5 帧，可设为 1–30 帧。

录音在浏览器内处理，音频不会自动保存到磁盘。缩短保留时长时会丢弃较早的音频；刷新、清空或开始新音频前，先下载需要保留的片段。

手机底部提供录音、目标、清空和回放；导入、下载、配置与关于在右上角「更多」。音高参考页可点击钢琴或用 Enter / 空格听参考音。

声音分析与音高参考共用音频和目标。进入「统计分析」会停止主分析的实时录音，保留已有分析数据；统计页使用自己的录音与报告。

需要观察真假音过渡时，打开「配置 → 声区校准」，可直接点击「开始录音」。在感受到的转换边界维持同一元音，点击「采集边界声」后保持音高与响度约 1.2 秒，稳定样本自动保存。已有校准时可「重新采样」或「恢复默认」；关闭配置会取消未完成采样，录音可继续。之后在相近音高、元音、响度和麦克风位置下比较，跨越较大音域或更换设备时重新校准。

## 统计分析

从第三个标签进入「统计分析」，可选中文、英文各两段朗读材料，也可自由说话或导入音频。片段上限独立为 60 秒，不受主分析页保留时长影响。点击「开始录音」后朗读；读完或需要停顿时点击「暂停录音」，再选择「继续录音」或「完成并分析」。

报告统计整段片段的有效 F0，显示中位数、P10/P90 和音高分布。切换到其他标签会暂停统计录音，保留草稿与最近报告，返回后可继续；刷新或关闭应用后清除。

## 交互演示与教学文档

「交互演示」同时提供声带调节、喉位、舌前后、舌高、圆唇与下颌六个滑块。桌面上方并列结构图与两列滑块，下方元音空间和频谱等宽并列；手机纵向排列。选择元音建立参考；调节滑块会同步改变剖面图、元音位置、频率和频谱。拖动元音图中的实心点，舌高、下颌与舌前后会一起变化。无法达到的组合停在当前声道参数的可达边界；「复位」恢复当前元音参考。头颈图保留完整圆颅顶与后脑，悬停部位可查看名称及引线。

选择 F0、F1、F2，可突出相关部位，无关滑块和结构灰显但仍可操作；「全部部位」恢复完整配色。喉位与圆唇同时影响 F1 和 F2。

F0 反映声源振动，F1、F2 反映声道共振。「声带调节」综合演示环甲肌、甲杓肌等对声带伸展、刚度和有效振动组织的协调变化，端点表示较低和较高音高。练习从舒适音域的轻柔滑音开始，再过渡到短音节、短句与日常说话，保留自然起伏；避免挤喉，声嘶或疲劳时休息。演示适合比较变化方向，参数独立于训练目标。

「教学文档」从目录进入，保留原手册的七章顺序、正文、表格和练习。通过左侧目录或手机章节选择器阅读，可复制当前地址保留章节与小节位置。26 个图位中15个以代码重绘，11个Praat操作与练习图保留真实截图并可查看原尺寸；男女元音空间图采用同一坐标尺度。原文中需修正的关键概念以校注说明。

「帮助」只提供本程序的操作与读图说明；完整训练方法请进入「教学文档」。
