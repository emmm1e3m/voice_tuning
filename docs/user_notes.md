# 声音练习室：当前说明

更新：2026-10-22。双击根目录「启动练习器.cmd」可本地运行。

五个页面依次为声音分析、音高参考、统计分析、交互演示、教学文档。声音分析与音高参考共用音频，进入统计分析会停止主分析的实时录音并保留已有数据。

## 统计分析

- 使用独立的60秒录音或导入片段，提供中文、英文各两段材料及自由说话；暂停后可继续录音，或选择「完成并分析」。
- 报告显示整段有效F0的中位数、P10/P90与音高分布。切换标签暂停统计录音并保留草稿、最近报告，返回可继续；刷新或关闭应用后清除。

## 交互演示

- 六个滑块对应声带调节、喉位、舌前后、舌高、圆唇和下颌；剖面图、元音位置、F0/F1/F2及频谱同步更新。桌面上方并列结构图与两列滑块，下方并列等宽元音空间与频谱；手机纵向排列。
- 拖动元音图实心点，舌高、下颌与舌前后协同变化；「复位」恢复当前元音。
- F0/F1/F2按钮用于查看相关部位。无关项灰显但仍可操作；喉位与圆唇同时影响F1和F2。
- 头颈图保留完整圆颅顶与后脑，悬停部位显示名称和引线；声带以独立俯视详图展示。教学模型用于比较动作的典型影响。

## 教学文档与帮助

- 「教学文档」从目录进入，按原手册七章阅读，保留正文、练习、表格和图序。桌面使用侧栏目录，手机使用章节选择；地址保留章节和小节位置。
- 26 个图位中15个以代码重绘，11个Praat操作与练习图保留真实截图，可查看原尺寸；男女元音空间图采用相同坐标尺度。原始资料保留作准确性校对。
- 关键概念附就近校注，保留原文出处与阅读上下文。提高F0涉及声带伸展、刚度和有效振动组织的协调调节；练习从舒适音域的轻柔滑音逐步过渡到短句，保持自然起伏，避免挤喉和疲劳发声。
- F0 练习说明沿用原文的讲解语气；专业文献统一列于文末，与原有参考文献连续编号。
- 「帮助」独立介绍本程序的录音、目标、读图、音频保存和排错，默认打开快速上手。

## 声音分析与目标

- 同一张时间—频率图显示F0/F1/F2、目标带和单层竖直声区背景，静音和缺口留白。「配置 → 声区校准」内可直接开始录音并采集约1.2秒稳定的真假音转换边界声；比较时保持相近音高、元音、响度和麦克风位置，跨较大音域或更换设备后重新校准。开关、对数/线性坐标和曲线显隐各自独立。
- 「目标频率设置」中的「随F0推荐」按所选元音与F0在手册两档参考值之间连续插值，参考档位外继续延伸；切换元音保留F0。手调共振峰进入手动模式，此时调整F0保留F1/F2。目标中心、元音与模式保存，参考半宽为F0 ±40、F1 ±100、F2 ±150 Hz。
- 默认平滑5帧、保留10秒，可设1–30帧与5–120秒。需要留存的音频应先下载WAV，缩短窗口会舍弃早期片段。
