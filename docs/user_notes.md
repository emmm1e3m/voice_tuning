# 声音练习室：当前说明

更新：2026-10-22。源码在 downloads/voice.starbow.top/source；双击根目录「启动练习器.cmd」可本地运行。

## 元音、发声结构与频谱联动

- 教程「发声部位与动作」在同一面板提供 a、o、e、i、u、ü 的口腔结构、F0/F1/F2 参考值和强度—频率二维图。
- 切换元音同步切换舌位、唇形和开口基准；选择声带张力、喉位、舌前后、舌高、圆唇或下颌，使用一个滑块查看结构与频谱变化。
- 显示参考值、当前值和 Hz 差值；参考虚线用于比较当前结构、共振包络和 F0 位置。复位回到当前元音。
- F0 表示基频和泛音间距；F1、F2 表示共振峰。数值基准沿用练习预设，滑块位移与相对强度属于教学模型，不是个人频率预测。

## 声音分析与目标

- 主页面仅一张时间—频率图，同时显示 F0/F1/F2、各自目标带和中心线。真声、混声、假声按录音时间着色为背景；静音和缺口留白。
- 「声区」开关位于对数/线性坐标选择旁，保存显示偏好；实时反馈中不再另列声区。声区是泛音特征估计，不是按频率高低划分。
- 三张窗口中位数卡片直接提示主要结构：F0 对应声带，F1 对应舌高与开口，F2 对应舌前后、圆唇与声道。
- 桌面「本次练习 · 目标中心」默认展开。「按元音推荐」采用所选元音的 F1/F2 参考区间，设置或切换时保留当前 F0；手调 F1/F2 会进入手动模式。
- F0 无法唯一确定个人 F1/F2，因此推荐依据元音参考。每项目标仍选择中心，半宽固定为 F0 ±40、F1 ±100、F2 ±150 Hz；可手动调整。
- 当前元音、目标值、设置方式与配置会保存；原有自定义目标迁移为手动模式，避免被推荐覆盖。

## 教程、配置与来源

- 「写在前面」为第一章，包含「为什么练习声音女性化」「避免练习误区」，之后才是「快速上手」；共 16 章。
- 共振峰算法说明已介绍混合 LPC/倒谱回退的用途、取舍和生效时机。关于页的来源与致谢对齐仓库 README。
- 默认平滑 5 帧，可设 1–30 帧；默认保留 20 秒，可设 5–120 秒。缩短保留时长会舍弃较早音频，扩容从后续声音继续累积。
