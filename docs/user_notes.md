## 配置与音频

平滑默认 5 帧，可设 1–30 帧；保留默认 20 秒，可设 5–120 秒。配置在浏览器中保存。保留时长同步影响图表窗口、录音缓冲、导入上限、回放与 WAV 下载。缩短会舍弃较早的音频，扩容从后续声音继续累积。

对 5/10 帧的对照显示：10 帧使样本曲线略平稳，但元音切换响应更慢，未提高参考误差表现，因此默认仍为 5 帧，使用者可直接改为 10。实验依据见 source/docs/smoothing-comparison.md。
