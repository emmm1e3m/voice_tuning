# 声音练习室 · 整合版

将实时声音练习与 MTF 手册放在同一应用中。桌面与手机依次提供「声音分析」「音高参考」「统计分析」「交互演示」「教学文档」五个页面标签。

## 启动与开发

推荐双击工作区根目录的 `启动练习器.cmd`。脚本准备本目录依赖、选择可用端口并在页面就绪后打开浏览器。

在本目录手动开发：

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

检查与 Pages 构建：

```powershell
npm test -- --testTimeout=15000
npx tsc --noEmit
npm run build -- --base=/voice_tuning/
```

## 分析与目标

- 声音分析页将 F0、F1、F2 放在同一张频率图上。默认以 2 为底的对数纵轴，可切换线性并保存选择；曲线、目标带、中心线和读数沿用同色：F0 紫、F1 粉、F2 蓝。
- 顶部三卡以「当前 Hz / 目标 Hz」显示当前保留窗口内各项有效频率的中位数与目标中心。点击卡片打开对应数值的使用说明。
- 声区以一层贯穿图高的竖直时间背景显示真声、混声与假声估计，静音和缺口留白。图例隐藏曲线时，窗口数值继续显示。
- 桌面目标菜单默认展开，摘要显示当前元音；手机在目标弹窗中编辑。每项只有一个中心数字输入和一个滑块，宽度统一为 F0 ±40 Hz、F1 ±100 Hz、F2 ±150 Hz。
- 「目标频率设置」中的「随F0推荐」按 F0 在手册成年男女两档元音参考中心之间插值，锚点外沿相同斜率延伸；切换元音保留 F0。手动修改共振峰进入手动模式，此时调整 F0 保留 F1/F2。各元音的目标及当前模式保存在浏览器中。
- 调整中心时保留完整宽度，在频率边界与 F1/F2 顺序边界处限制所编辑的中心，并给出提示。旧自定义范围按中点迁移，迁移前的存储内容单独备份。
- 界面共用 12/13/14/16 px 字号，页面标题 32 px、章节标题 22 px；工具、重置和帮助入口使用统一图标。

「配置 → 声区校准」可直接开始/停止录音，并采集约 1.2 秒稳定的真假音转换边界声，以谐波峰数量设置个人边界；同处可重新采样或恢复默认。比较时保持相近音高、元音、响度与麦克风位置；跨越较大音域或更换设备时重新校准。结果用于观察换声过渡。

## 音频与配置

| 配置 | 默认值 | 可选范围 | 生效方式 |
| --- | --- | --- | --- |
| 频率平滑窗口 | 5 帧 | 1–30 帧 | 下次录音或导入 |
| 音频保留时长 | 10 秒 | 5–120 秒 | 提交后调整保留音频、图表窗口与导入上限 |

帧步长为 10 ms。平滑可关闭，算法可选混合、LPC 或倒谱；算法选择从下次录音或导入生效。配置保存在当前浏览器中。

声音分析与音高参考共用音频，录音可以持续进行，缓冲只保留最近设定时长的音频。短音频按实际时长铺开显示，长录音滚动显示保留窗口。缩短时长会舍弃较早样本，之后增大时长不会恢复已舍弃的部分。

支持导入、回放与 WAV 下载。导入时长不得超过当前保留时长；下载格式为 16 kHz、单声道、PCM16，导出前会停止正在进行的录音或回放。音频在浏览器内处理，不自动写入磁盘。

## 统计分析

「统计分析」（`#/statistics`）独立录制或导入最长60秒的片段，提供中文、英文各两段材料及自由说话。暂停后可继续录音或完成分析，报告支持整段回放，显示有效F0的中位数、P10/P90与音高分布。进入统计页会停止主实时录音；切换标签暂停统计录音并保留草稿和最近报告，返回可继续。统计数据在当前应用会话中临时保留，刷新或关闭应用后清除。

## 交互演示、教学文档与帮助

「交互演示」在一个工作区中联动声道剖面、元音空间、F0/F1/F2 读数与频谱，同时显示声带调节、喉位、舌前后、舌高、圆唇与下颌六个滑块。桌面上方为结构图与两列三行滑块，下方元音空间和频谱等宽并列；手机纵向排列。拖动滑块或元音探索点都会更新同一组发声参数；拖图时保留声带调节、唇形和喉位，调整舌与下颌，超出可达范围时显示实际边界。头颈图保留完整圆颅顶与后脑，悬停部位显示名称和引线。演示参数独立于训练目标。

「声带调节」两端表示较低与较高音高，综合演示喉内肌对声带伸展、刚度和有效振动组织的协调作用。练习从舒适音域轻柔滑音逐步过渡到短句，保留自然起伏；避免挤喉，声嘶或疲劳时休息。

「教学文档」从目录进入，按原手册七章顺序保留正文、表格、练习与参考文献。26 个图位中，15 个以代码重绘，11 个 Praat 操作与练习图保留真实截图；男女元音空间图共用坐标尺度。关键概念提供校注，章节与小节记录在地址中，可直接分享阅读位置。原手册离线存档保留在 `public/manual/`。

「帮助」提供本程序的录音、读图、目标设置、统计分析和排错说明。读图示例演示同一时间轴上的三条频率轨迹、目标带、中心线与停顿断点；完整训练原理与方法从「教学文档」阅读。

应用「关于」列出文档作者、手册网站、原项目仓库和原项目在线体验四个来源链接。
