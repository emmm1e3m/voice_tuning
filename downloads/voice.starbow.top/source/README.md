# 声音练习室 · 整合版

将实时声音练习与 MTF 手册学习内容放在同一应用中。桌面与手机提供固定的「声音分析」「音高参考」两个页面标签。

## 启动与开发

推荐双击工作区根目录的 `启动练习器.cmd`。脚本准备本目录依赖、选择可用端口并在页面就绪后打开浏览器。

在本目录手动开发：

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

检查与构建：

```powershell
npm test
npm run build
npx tsc --noEmit
```

## 分析与目标

- 声音分析页将 F0、F1、F2 放在同一张频率图上。默认以 2 为底的对数纵轴，可切换线性并保存选择；曲线、目标带、中心线和读数沿用同色：F0 紫、F1 粉、F2 蓝。
- 顶部三卡以「当前 Hz / 目标 Hz」显示当前保留窗口内各项有效频率的中位数与目标中心。点击卡片打开对应原理和训练方法。
- 实时反馈显示最新一帧的 F0、F1、F2 与声区。图例隐藏曲线时，这些关键数值继续显示。
- 桌面目标菜单默认收起，摘要显示当前元音；手机在目标弹窗中编辑。每项只有一个中心数字输入和一个滑块，宽度统一为 F0 ±40 Hz、F1 ±100 Hz、F2 ±150 Hz。
- 调整中心时保留完整宽度，在频率边界与 F1/F2 顺序边界处夹紧所编辑的中心，并给出提示。旧自定义范围按中点迁移，迁移前的存储内容单独备份。
- 界面与图表字号按 125% 呈现，工具、重置和帮助入口使用统一的粗线图标。

## 音频与配置

| 配置 | 默认值 | 可选范围 | 生效方式 |
| --- | --- | --- | --- |
| 频率平滑窗口 | 5 帧 | 1–30 帧 | 下次录音或导入 |
| 音频保留时长 | 20 秒 | 5–120 秒 | 提交后调整保留音频、图表窗口与导入上限 |

帧步长为 10 ms。平滑可关闭，算法可选混合、LPC 或倒谱；算法选择从下次录音或导入生效。配置保存在当前浏览器中。

录音可以持续进行，缓冲只保留最近设定时长的音频。短音频按实际时长铺开显示，长录音滚动显示保留窗口。缩短时长会舍弃较早样本，之后增大时长不会恢复已舍弃的部分。

支持导入、回放与 WAV 下载。导入时长不得超过当前保留时长；下载格式为 16 kHz、单声道、PCM16，导出前会停止正在进行的录音或回放。音频在浏览器内处理，不自动写入磁盘。

## 内置学习

以手册正文和插图为基础，补充舌骨、喉外肌、舌与唇颌动作的关系，以及练习步骤和读图说明。16 道复习题先显示题目，点击后展开答案。

三幅交互图分别用于探索发声部位、声源与滤波器、F1/F2 元音空间；读图示例展示同一时间轴上的三条频率轨迹、目标带、中心线与停顿断点。交互教学图的参数独立于练习目标。

原手册离线入口保留在 `public/manual/`，也可从帮助面板打开。应用「关于」列出两个来源网站。
