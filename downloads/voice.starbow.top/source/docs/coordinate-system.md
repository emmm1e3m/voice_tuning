# 时间坐标、窗口统计与回放游标

更新日期：2026-10-19。

## 可配置时间窗口

分析页在同一张图里显示 F0、F1、F2，共用时间轴；音高参考图沿用相同的时间窗口函数。窗口由「配置 → 音频保留时长」决定，默认 20 秒，可设置为 5–120 秒。

以保留时长 `T`、最后一帧时间 `lastTime` 表示：

- 空数据：横轴 `[0, T]`。
- 有数据：`min = max(0, lastTime - T)`，`max = max(lastTime, 1)`。

默认 `T = 20` 时：

| 数据状态 | 横轴范围（秒） |
| --- | --- |
| 空数据 | `[0, 20]` |
| 最后一帧为 0.3 秒 | `[0, 1]` |
| 最后一帧为 2 秒 | `[0, 2]` |
| 最后一帧为 20 秒 | `[0, 20]` |
| 最后一帧为 35 秒 | `[15, 35]` |

短音频按实际时长铺开；不足一秒时仍显示一秒宽度。超过保留时长后随录音滚动。改变时长立即调整显示窗口与保留容量，帧本身的 `time` 不变。

横轴标示秒，手机使用较少刻度。悬浮预览的时间取整数，时间轴刻度可保留小数；这些格式化只改变文字，不改变音频或游标时间。

## 频率纵轴与目标中心

共振峰分析图默认使用以 2 为底的对数纵轴，可切换线性。对数显示使倍频程等距，底层 F0/F1/F2 与所有目标仍以 Hz 保存。

目标带沿用固定宽度：F0 中心 ±40 Hz、F1 中心 ±100 Hz、F2 中心 ±150 Hz。虚线定位在上下沿的算术中点，与目标中心输入一致；对数轴中这条线不要求处于色带的视觉正中。

缺失、非有限或非正的频率值形成断点，横轴时间不因断点压缩。图表会容纳有效频率数据，曲线显隐不改变实时数值和窗口统计。

## 窗口概况与实时反馈

上方三卡对当前保留窗口内各项有效频率分别取中位数。偶数个样本时取中间两项的均值，停顿、0、负值、NaN 和无穷值不参与统计；完全没有有效值时显示占位符。每卡同时显示当前目标中心，便于比较。

实时反馈读取最新一帧，持续显示声区及 F0、F1、F2。两种读数共用 Hz 单位，统计窗口概况与当前发声状态分别更新。

## 回放与保留样本

原始音频缓冲保留最近 `T` 秒，默认 20 秒。音频采样率为 16 kHz，分析帧步长为 10 ms；保留容量与配置同步。缩短窗口会舍弃较早样本和帧，增大窗口只为后续录音提供更多空间。

回放基于保留的真实采样，起点与帧的绝对时间对应。游标通过 `xAxis: cursorTime` 定位，分析图与音高参考图共享同一个回放时间。切换频率轴、隐藏曲线或进入另一页面均不会重新换算时间。

修改保留时长会停止当前回放。录音达到窗口时长后继续进行；下载保存当前保留片段，导入文件的时长上限同样为 `T`。
