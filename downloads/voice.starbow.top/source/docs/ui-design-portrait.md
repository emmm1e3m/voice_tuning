# 声音练习室 · 竖屏 UI 规范

更新于 2026-10-22。适用宽度不超过 768px；设计检查以 390 × 844 CSS px 为基准，覆盖 360px 窄屏和较矮视口。共享行为见 `ui-design.md`，尺寸和颜色以当前 CSS 为准。

## 页面与导航

顶部共享品牌、更多菜单和五个页面标签，依次为「声音分析」「音高参考」「统计分析」「交互演示」「教学文档」。品牌与更多位于第一行，标签独占第二行，窄屏保持五个入口可见。

五页使用 HashRouter：`#/`、`#/practice`、`#/statistics`、`#/interactive`、`#/manual`。页面切换和浏览器前进后退同步更新选中项，保留 Pages 路径前缀。声音分析与音高参考共用音频、分析数据和目标；进入统计页停止主实时录音并保留已有数据。

声音分析与音高参考页提供固定底部录音栏；声音分析页另有目标入口。统计与教学页不显示共享 Dock 和首次使用提示，统计页提供独立录音控件，其更多菜单仅保留帮助与关于。

应用高度使用 `100dvh`，页面内容在剩余区域纵向滚动。固定底部栏和安全区不能遮挡最后一项内容；不绘制模拟设备状态栏。

## 声音分析

内容依次为保留窗口概况和频率图。窗口三卡显示有效频率中位数与目标中心，停顿不算 0；卡片点击打开对应的程序数值说明。共享字号为 12/13/14/16 px，页面标题 32 px、章节标题 22 px。

分析页只使用一张图显示 F0/F1/F2，颜色统一为紫 `#8b67c5`、粉 `#d76e97`、蓝 `#5c92c7`。曲线、目标区域、中心虚线和标签保持对应颜色。默认对数坐标，可切换线性。声区使用一层贯穿图高的竖直时间背景，表示真声、混声、假声估计，静音和缺口留白；隐藏 F0 曲线不隐藏声区。右上角「更多 → 配置」中的「声区校准」可直接开始/停止录音，再采集约 1.2 秒稳定的真假音转换边界声，按谐波峰数量保存个人边界；比较时保持相近音高、元音、响度与麦克风位置，跨大音域或换设备时重新校准。

图表与音频共用可配置的保留窗口，默认 10 秒，可设 5–120 秒。短录音按实际时长显示，长录音滚动保留最近窗口。回放游标与悬浮数据使用真实时间戳。

## 音高参考

内容顺序为钢琴键盘、音高图。左右滑动查看其他音域，轻点琴键或聚焦后按 Enter、空格听参考音；检测到的音高可高亮对应琴键。音高图复用横版的音符纵轴、参考线、时间轴、回放游标及悬浮说明。

音高参考页不显示训练目标入口；底部录音、清空与回放继续可用。

## 统计分析

页面内选择中文、英文各两段材料或自由说话，可独立录制或导入最长60秒的片段。「暂停录音」后可「继续录音」或「完成并分析」，报告显示整段有效F0的中位数、P10/P90与音高分布。切换标签暂停统计录音并保留草稿、最近报告，返回可继续；刷新或关闭应用后清除。统计时长不受主分析页保留窗口影响。

## 交互演示

声道剖面、六个部位滑块及频率读数、元音位置与频谱依次按窄屏宽度排列。六个滑块同时存在，每项提供名称、两端方向及对应变化说明；「声带调节」两端为「较低音高／较高音高」。

选择 a、o、e、i、u、ü 切换参考。滑块改变同一组发声参数，剖面、元音点和频谱同步；元音点支持触屏拖动。拖图保留声带调节、唇形与喉位，调整舌高、下颌及舌前后；无法达到的组合停在实际边界。圆唇与喉位影响共振，声带调节综合表示伸展、刚度和有效振动组织对 F0 的影响。演示状态不改写训练目标。

头颈图保留完整圆颅顶与后脑，悬停部位显示名称和引线；频谱保留必要标注。完整图需要横向空间时只在组件内部滚动，页面本身不横向溢出；复位返回当前元音。

## 教学文档

手机使用章节选择器，默认从目录进入，保留原手册七章顺序。正文、表格、练习和参考文献按原文阅读；26 个图位保留 15 个代码图及 11 个真实 Praat 截图，男女 VSA 图使用相同坐标尺度。关键概念附校注；章节与小节记录在地址中，刷新或分享后可回到对应位置。

正文和插图可纵向滚动，较宽图表允许内部横向滚动，避免缩到标注无法辨认。页面无录音 Dock，充分利用阅读区域。

## 目标设置

声音分析页的底部目标入口打开「目标频率设置」Modal。六元音分别保留目标，按钮统一使用 a、o、e、i、u、ü；每个 F 使用一个中心输入和一个滑块，固定半宽为 F0 ±40、F1 ±100、F2 ±150 Hz。

「随F0推荐」按 F0 在手册成年男女两档元音参考中心之间插值，锚点外沿相同斜率延伸，切换元音保留 F0；手动修改共振峰切换到手动模式，此时调整 F0 保留 F1/F2。数字输入时只更新草稿，失焦或 Enter 后校验并提交；滑块实时生效。中心必须为半宽留出边界，并保持 F1 上沿不高于 F2 下沿；调整时不改变固定宽度。

必要的边界提示通过输入校验气泡呈现，不增加常驻规则按钮。重置需确认，恢复全部元音默认值并切回 a，同时清除草稿与提示。弹窗支持 Esc、Tab 焦点约束、背景滚动锁定和关闭返回入口；打开与调整目标不暂停录音。

从竖屏转为横屏或进入统计、教学页时关闭目标弹窗，清除其打开状态。

## 底部录音栏与更多菜单

录音按钮居中，清空与回放分列两侧，声音分析页显示目标入口。按钮提供可访问名称、键盘焦点和禁用状态；麦克风授权中禁用录音，录音中可停止。回放中按钮改为停止。

导入、下载、配置、帮助、关于放在更多菜单。清空只清除声音数据，保留配置和训练目标。配置、帮助、关于不打断音频。WAV 下载前停止录音或回放，格式为 16 kHz 单声道 PCM16。

## 主动帮助

声音分析和音高参考页共用一次性提示及本地完成标记。无数据空闲时显示；授权、录音、回放、已有数据及应用弹层打开时暂时隐藏。关闭或首次有效分析后持续隐藏；仅阅读帮助不计完成。

声音分析、音高参考及教学页的「更多 → 帮助」和首次提示的「查看说明」打开快速上手；统计页的帮助打开统计分析。F0/F1/F2 卡片打开对应数值说明，共振峰图问号打开读图，音高图问号打开音高参考。帮助共十个主题，使用手机选择器；正文只包含程序操作，页脚链接教学文档与交互演示。

帮助支持 Esc、Tab 焦点约束和关闭恢复焦点。跨横竖屏保留当前主题和逻辑目录焦点；原入口不可用时回到当前录音按钮，录音禁用时回到帮助或更多。帮助、配置、关于、训练目标同时仅打开一个。
