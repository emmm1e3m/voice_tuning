# 声音练习室 · UI 与帮助交互规范

更新于 2026-10-22。本文记录当前实现；竖屏规则见 `ui-design-portrait.md`，历史方案见 `docs/superpowers/`。

## 页面与主要操作

- 顶部按「声音分析」「音高参考」「统计分析」「交互演示」「教学文档」顺序提供五个页面标签，与 HashRouter 路由同步；统计页对应 `#/statistics`。
- 「声音分析」显示窗口中位数、目标中心及同一图中的 F0/F1/F2；「音高参考」提供钢琴与音高图。
- 「交互演示」联动六个发声滑块、声道剖面、元音空间和频谱；「教学文档」独立阅读完整原手册。
- 宽度超过 768px 使用横版，宽度不超过 768px 使用竖版。竖屏分析与音高参考页使用底部录音栏，更多菜单承载导入、下载、配置、帮助和关于。
- 统计与教学页隐藏共享底部录音栏和首次使用提示；统计页使用自己的录音控件。声音分析与音高参考共用音频，进入统计页停止主实时录音并保留已有数据；离开统计页会暂停统计录音，保留草稿和最近报告。
- 帮助、配置、关于及目标设置同时只打开一个；阅读帮助不停止音频，不申请麦克风权限。
- 字号共用 12/13/14/16 px 层级，页面标题 32 px、章节标题 22 px。

## 主动帮助入口

不显示随机小提示，不自动打开帮助模态框。声音分析与音高参考页共用一次性的首次使用提示及本地完成标记。

| 入口 | 打开的主题 |
|---|---|
| 声音分析、音高参考及教学页的「帮助」 | 快速上手 |
| 统计页「帮助」或标题旁问号 | 统计分析 |
| 首次使用提示「查看说明」 | 快速上手 |
| F0/F1/F2 窗口卡片、目标旁帮助 | 对应数值说明 |
| 共振峰图标题旁问号 | 读图与反馈 |
| 音高图标题旁问号 | 音高参考 |

图表说明通过点击打开，支持键盘操作。空状态保留说明文字，帮助由首次提示、图表问号或菜单主动打开。目标卡片不增加规则按钮，输入校验气泡继续使用。

### 共享首次使用提示

- 标题「第一次使用？」、副文案「了解录音、读图与目标设置」，按钮「查看说明」，右侧可关闭。
- 提示脱离文档流，不改变图表高度；横屏位于右下角，竖屏位于实测 Dock 上方，外层事件穿透。
- 分析与音高参考页无数据空闲时显示；授权、录音、回放、已有数据或应用弹层打开时暂时隐藏，统计与教学页始终隐藏。
- 关闭提示或首次产生任一有限且大于 0 的 F0/F1/F2 分析值后持续隐藏；仅阅读帮助不计为完成。
- 本地键 `voicebuilder-intro-hint-v1` 保存完成标记；清空图谱不清除该标记。

## 帮助面板

使用共享 Modal，标题为「使用说明」。十个主题按快速上手、F0、F2、F1、读图与反馈、训练目标、录音与导入、音高参考、统计分析、遇到问题组织。桌面为侧边目录，手机为主题选择器。

- 内容仅面向程序操作，不混入完整手册章节。页脚分别链接「教学文档」与「交互演示」。
- 快速上手介绍录音、回放读图和目标设置；操作位置随横竖屏更新。
- 主题切换后正文回到顶部，关闭按钮始终可用。读图主题内可切换示例曲线，观察目标带、中心线与停顿断点。
- 支持 Esc 关闭、Tab 焦点约束和关闭返回原入口。入口不可用时返回当前录音按钮；录音禁用时退到帮助或更多按钮。
- 跨布局保留主题，目录与选择器之间维持逻辑焦点；不重置正文阅读位置。

## 统计分析

独立录制或导入最长60秒的片段，提供中文、英文各两段材料及自由说话。录音先暂停，再继续或「完成并分析」；报告显示整段有效F0的中位数、P10/P90与音高分布。切页暂停并保留草稿和最近报告，返回可继续；刷新或关闭应用后清除。主分析页保留窗口不影响统计时长。

## 教学页面

交互演示在桌面上方并列结构图与两列三行滑块及读数，下方元音空间和频谱等宽并列；手机纵向排列。六个滑块同时显示，滑块、元音点、剖面及频谱共用同一组状态。元音点支持指针拖动，拖图保留声带调节、唇形与喉位，通过舌与下颌调整共振峰。超出当前声道的可达范围时显示实际边界，复位返回当前元音。头颈图展示完整圆颅顶与后脑，悬停部位显示名称和引线。演示不修改训练目标。

「声带调节」端点为「较低音高／较高音高」。内部 `tension` 是纵向伸展、刚度与有效振动组织的合并教学参数，表达环甲肌、甲杓肌等的协调作用，不能解释为用力程度或单纯长短变化。

教学文档从目录进入，按原手册七章保留正文与练习。桌面目录和手机章节选择器使用同一索引；章节、小节写入地址，可直接访问。26 个图位中，15 个代码重绘，11 个 Praat 操作与练习图保留真实截图；男女 VSA 图采用统一坐标尺度。原文关键概念的修正通过校注呈现。

## 数据与说明

- 程序帮助统一由 `src/content/helpContent.ts` 维护，手册正文见 `src/content/manualDocument.ts` 与 `src/content/manual/`。
- 「目标频率设置」的元音按钮为 a、o、e、i、u、ü。「随F0推荐」按 F0 在手册成年男女两档元音参考中心之间插值，锚点外沿相同斜率延伸，依据见 `targetBandRules.ts`。手动修改共振峰关闭推荐；手动模式调整 F0 保留 F1/F2，切换元音保留 F0。默认初始化与重置同样使用推荐规则，用户目标单独保存。固定半宽为 F0 ±40、F1 ±100、F2 ±150 Hz。
- 图表范围读取 `analysisRanges.ts`。F0/F1/F2 统一使用紫、粉、蓝；声区使用一层贯穿图高的竖直时间背景，静音与缺口留白。「配置 → 声区校准」内可直接开始/停止录音并采集约 1.2 秒稳定边界声，按谐波峰数量保存个人边界；支持重新采样、取消采样及恢复默认。比较时保持相近音高、元音、响度与麦克风位置，跨大音域或换设备后重新校准。
- 声音分析与音高参考默认保留 10 秒，可设 5–120 秒；配置范围来自 `appConfig.ts`。保留时长同步用于导入上限、图表、回放和下载，主实时录音持续覆盖旧样本；统计页独立限60秒。
- 数字输入失焦或 Enter 提交，滑杆实时生效。恢复默认值清除全部元音覆盖并切回 a，需要确认。
- 按钮名使用「导入音频」；WAV、MP3、M4A 解码取决于编码与浏览器支持。

## 验收

检查五页切换、HashRouter 深链、横竖屏帮助目录、焦点恢复、360px 窄屏及矮屏正文滚动。验证六滑块和元音点双向联动、教学章节导航、主分析与参考共用音频，以及统计录音独立和切页暂停恢复。
