# 整合版界面与交互

更新日期：2026-10-22。

## 页面与阅读顺序

采用浅粉、浅蓝、暖白背景和蓝色主操作。共享字号为 12/13/14/16 px，页面标题 32 px、章节标题 22 px；操作图标统一使用 `Icon.tsx`。

顶部依次提供「声音分析」「音高参考」「统计分析」「交互演示」「教学文档」五个导航标签。应用使用 HashRouter，五页分别对应 `#/`、`#/practice`、`#/statistics`、`#/interactive`、`#/manual`，保留 Pages 的 `/voice_tuning/` 路径前缀。

分析页按「保留窗口概况 → 频率曲线」组织信息；音高参考页保留可点击、触控和键盘激活的钢琴。上方 F0、F1、F2 三卡显示保留窗口的有效频率中位数和目标中心；无效值与停顿不按 0 参与统计。点击卡片打开程序说明。桌面目标卡与右侧图表对齐，默认展开并可收起。

## 统计分析

统计页独立录制或导入最长60秒的片段，提供中文、英文各两段材料及自由说话。录音可暂停、继续；暂停后选择「完成并分析」，显示整段有效F0的中位数、P10/P90和音高分布。

主分析与音高参考共用音频，进入统计页会停止主分析的实时录音，保留已有分析数据。切换到其他标签会暂停统计录音，保留草稿与最近报告，返回统计页可继续；刷新或关闭应用后清除统计数据。

## 目标频率设置

桌面「目标频率设置」使用原生 `details/summary`，默认展开，摘要显示当前元音；Enter、空格和鼠标均可切换展开状态。重置按钮位于表头。手机从底部目标入口打开同名弹窗。元音按钮统一使用 a、o、e、i、u、ü。

各项共用一套中心规则与编辑组件，提供一个数字输入和一个滑块：

| 项目 | 固定半宽 | 固定全宽 | 总频率边界 |
| --- | --- | --- | --- |
| F0 | ±40 Hz | 80 Hz | 0–500 Hz |
| F1 | ±100 Hz | 200 Hz | 0–3500 Hz |
| F2 | ±150 Hz | 300 Hz | 0–3500 Hz |

中心需为两侧半宽留出空间，同时保持 F1 上沿不高于 F2 下沿。超出边界时限制所编辑的中心并显示提示。滑块实时生效，数字输入在 Enter 或移开焦点时提交；支持方向键、PageUp/PageDown、Home/End。

「随F0推荐」根据当前元音与 F0 连续调整 F1、F2。两档共振峰取手册普通话成年男女表的区间中点，按 F0 在档位之间插值，锚点外沿相同斜率延伸；该映射用于推荐练习目标，不预测个人声道。手改共振峰进入手动模式，手动模式调整 F0 保留 F1/F2；重新启用推荐立即重算。六个元音分别保存目标，切换元音保留当前 F0 与推荐/手动模式。旧自定义上下界按中点迁移；相互冲突的中心规范化为有序组合。迁移前原始存储保存在 `voicebuilder-presets-before-center-targets-v2`。规则见 `src/config/targetBandRules.ts`，持久化见 `src/store/appStore.ts`。

每项旁的帮助图标打开对应数值的使用说明。收起桌面目标菜单后，窗口概况与频率图仍可查看。

## 一张图与窗口读数

分析页使用一张共振峰图，同时画 F0、F1、F2。曲线、浅色目标带、中心虚线和数值使用统一颜色：

| 项目 | 颜色 | 对应含义 |
| --- | --- | --- |
| F0 | 紫 `#8b67c5` | 音高与声带振动 |
| F1 | 粉 `#d76e97` | 元音开闭与舌位 |
| F2 | 蓝 `#5c92c7` | 元音前后、唇形与音色 |

默认使用以 2 为底的对数频率轴，可切换线性并保存选择。底层数据保持 Hz。非正值、NaN、无穷值和缺失值形成断点。窗口中位数反映当前保留片段的总体位置；中心虚线与输入的目标中心一致。

声区以单层、贯穿图高的竖直时间背景显示真声、混声、假声估计；静音和缺口留白。声区开关独立于曲线显隐。「配置 → 声区校准」可直接开始/停止录音，采集约 1.2 秒稳定边界声，根据谐波峰数量保存个人边界；支持重新采样、取消采样与恢复默认。关闭配置取消未完成采样，录音可继续。比较需保持相近音高、元音、响度与麦克风位置，跨越较大音域或换设备时重新校准。悬浮预览中的频率和时间按整数显示，原始帧、回放和游标保留真实数值。时间窗口详见 [coordinate-system.md](coordinate-system.md)。

## 配置、录音与保存

默认开启 5 帧频率平滑，可设为 1–30 帧，每帧间隔 10 ms。较大窗口能抑制短时毛刺，也会减慢变化；平滑与算法设置从下次录音或导入生效。

声音分析与音高参考共用的音频默认保留最近 10 秒，可设为 5–120 秒。该值同步用于缓冲、分析帧容量、图表窗口、回放、下载与导入时长上限；统计页的60秒上限独立。数字输入在 Enter 或失焦后提交。缩短时舍弃较早音频，增大时不会恢复旧数据；修改保留时长会停止当前回放。

录音持续进行，达到保留时长后滚动覆盖旧样本。WAV 下载保存保留的真实音频，格式为 16 kHz、单声道、PCM16；下载前停止录音或回放。音频不会自动保存到磁盘。

手机的分析与音高参考页底部放置录音、清空和回放，分析页另有目标入口；导入、下载、配置、帮助与关于在「更多」菜单中。统计页使用页面内的独立录音控件，统计与教学页均隐藏共享底部录音栏及首次使用提示。

## 交互演示、教学文档与帮助

「交互演示」桌面上方并列声道结构图与六个滑块（两列三行）及频率读数，下方元音空间与频谱等宽并列；手机纵向排列。选择元音切换参考位置；调节滑块改变剖面、元音探索点和声学结果，拖动探索点反过来调整舌高、下颌与舌前后。拖图保留声带调节、唇形与喉位，超出可达范围时显示实际边界；复位回到当前元音。剖面保留完整圆颅顶与后脑，悬停部位显示名称及引线。模型用于演示典型变化方向，不修改训练目标。

「教学文档」从目录进入，保留原手册七章顺序、正文、表格、练习与参考文献，并为关键概念添加校注。26 个图位包括 15 个代码图与 11 个真实 Praat 截图；男女 VSA 图使用统一坐标尺度。桌面使用目录，手机使用章节选择器；地址记录章节与小节位置。原文离线存档仍在 `public/manual/`。

「帮助」只说明本程序的录音、读图、目标设置、音高参考、统计分析和排错；帮助内保留可交互的 F0/F1/F2 读图示例。统计页的帮助默认打开统计主题。原理和训练方法从独立「教学文档」阅读，发声部位联动从「交互演示」探索。

「关于」列出文档作者、手册网站、原项目仓库、原项目在线体验四个来源链接。

在源码目录使用 `npm ci`、`npm run dev`。检查命令为 `npm test -- --testTimeout=15000`、`npx tsc --noEmit`、`npm run build -- --base=/voice_tuning/`。根目录启动脚本调用本目录的 Vite，监听 `127.0.0.1`，流程见根目录启动说明。
