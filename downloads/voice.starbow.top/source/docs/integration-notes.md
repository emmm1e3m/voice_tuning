# 整合版界面与交互

更新日期：2026-10-19。

## 页面与阅读顺序

采用浅粉、浅蓝、暖白背景和蓝色主操作，界面及图表字号按 125% 呈现。操作图标统一使用 `Icon.tsx` 的网格、粗线宽与圆端点。

顶部固定提供「声音分析」「音高参考」两个导航标签。分析页按「保留窗口概况 → 当前实时反馈 → 频率曲线」组织信息；音高参考页保留可点击、触控和键盘激活的钢琴。

上方 F0、F1、F2 三卡保持一行，各卡显示保留窗口内的有效频率中位数和当前目标中心，单位为 Hz；无有效频率时显示占位符。无效值与停顿不会按 0 参与统计。卡片点击后进入该项原理与练习方法。

实时反馈持续显示声区与最新一帧的 F0、F1、F2；桌面放在侧栏的目标菜单之前，手机放在图表上方。图例的显隐只作用于曲线，关键实时结果保持显示。

## 目标中心

桌面「本次练习 · 目标中心」使用原生 `details/summary`，默认收起并显示当前元音；Enter、空格和鼠标均可展开。重置按钮位于展开内容的表头。手机从底部目标入口打开弹窗，表单直接显示。

各项共用一套中心规则与编辑组件，提供一个数字输入和一个滑块：

| 项目 | 固定半宽 | 固定全宽 | 总频率边界 |
| --- | --- | --- | --- |
| F0 | ±40 Hz | 80 Hz | 0–500 Hz |
| F1 | ±100 Hz | 200 Hz | 0–3500 Hz |
| F2 | ±150 Hz | 300 Hz | 0–3500 Hz |

中心需为两侧半宽留出空间，同时保持 F1 上沿不高于 F2 下沿。超出边界时夹紧所编辑的中心并显示简短提示，完整宽度与其它项的位置保持不变。滑块实时生效，数字输入在 Enter 或移开焦点时提交；滑块支持方向键、PageUp/PageDown、Home/End。

六个元音使用相同宽度，默认中心沿用旧预设中点。已有自定义上下界读取后按中点迁移；相互冲突的中心投影为最近的有序组合。迁移前原始存储保存在 `voicebuilder-presets-before-center-targets-v2`，已有备份保持不变。中心规则在 `src/config/targetBandRules.ts`，持久化处理在 `src/store/appStore.ts`。

每项旁的帮助图标可直接打开对应原理与训练方法。收起桌面目标菜单后，窗口概况与实时反馈仍可查看。

## 一张图与两种读数

分析页使用一张共振峰图，同时画 F0、F1、F2。曲线、浅色目标带、中心虚线和数值使用统一颜色：

| 项目 | 颜色 | 学习主题 |
| --- | --- | --- |
| F0 | 紫 `#8b67c5` | 音高与声带振动 |
| F1 | 粉 `#d76e97` | 元音开闭与舌位 |
| F2 | 蓝 `#5c92c7` | 元音前后、唇形与音色 |

默认使用以 2 为底的对数频率轴，100→200 与 200→400 Hz 距离相同；可切换线性并保留浏览器中的选择。底层数据仍为 Hz。非正值、NaN、无穷值和缺失值形成断点；目标下沿为 0 时，对数模式不画该目标带，线性模式可以显示。

窗口中位数反映当前保留片段的总体位置，实时反馈反映最新一帧。中心虚线取目标上下沿的算术中点，与中心输入一致。悬浮预览中的频率和时间按整数显示，原始帧、回放和游标保留真实数值。时间窗口详见 [coordinate-system.md](coordinate-system.md)。

## 配置、录音与保存

默认开启 5 帧频率平滑，窗口可在 1–30 帧间设置，每帧间隔 10 ms。较大窗口能抑制短时毛刺，也会减慢变化；平滑与算法设置从下次录音或导入生效。

音频默认保留最近 20 秒，可配置为 5–120 秒。该值同步用于音频缓冲、分析帧容量、图表窗口、回放、下载与导入时长上限。输入在 Enter 或失焦后提交。缩短时舍弃较早音频，增大时不会恢复已舍弃的数据；修改保留时长会停止当前回放。

录音持续进行，达到保留时长后滚动覆盖旧样本。WAV 下载保存保留的真实音频，格式为 16 kHz、单声道、PCM16。下载前停止录音或回放，无样本时给出提示。音频不会自动保存到磁盘。

手机底部放置录音、目标、清空和回放；导入、下载、配置、帮助与关于在「更多」菜单中。

## 教程与来源

帮助面板以手册正文和插图为基础，扩充发声结构、声源与滤波器、共振峰、元音动作和练习步骤。章节内加入 16 道复习题，答案默认折叠，点击题目后展开。

三幅交互图分别为：发声部位示意、声源与滤波器实验、F1/F2 元音空间。另有 F0/F1/F2 读图示例，可切换示例曲线，观察目标带、中心线和停顿处的断点。交互参数只作用于教学示意。

原手册离线副本在 `public/manual/`。应用「关于」仅列 [在线声音训练](https://voice.starbow.top/) 与 [MTF 声音女性化练习手册](https://mtf-voice-training.vercel.app/) 两个来源入口，已移除原个人联系方式和旧更新日志。

## 开发入口

在源码目录使用 `npm ci`、`npm run dev`；检查命令为 `npm test`、`npm run build`、`npx tsc --noEmit`。根目录一键脚本调用本目录的 Vite，监听 `127.0.0.1`，启动流程见根目录启动说明。

继承的旧设计稿和实验文档保留作历史资料。下载时的 `manifest.json` 记录原始获取来源；整合后的行为和实现位置以本说明及当前源码为准。
